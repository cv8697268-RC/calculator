# Scientific Calculator using Python

A simple command-line Scientific Calculator developed using Python.  
It performs basic arithmetic, power, square root, trigonometric, and logarithmic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Square Root
- Sin
- Cos
- Tan
- Logarithm (Base 10)
- Exit option
- Division-by-zero handling

## Technologies Used

- Python
- Python `math` module

## Concepts Used

- Variables
- Conditional statements
- `while` loop
- User input
- Functions from the `math` module
- Basic problem-solving
